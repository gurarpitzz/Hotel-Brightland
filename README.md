## 📌 Project Overview

This project represents a complete architectural rewrite and modernization of the Brightland Hotel website. Transitioning from a legacy system to a state-of-the-art Next.js architecture, this platform is designed to maximize direct bookings via a high-conversion, WhatsApp-first funnel, completely bypassing OTA (Online Travel Agency) commission fees.

### Key Engineering Features
* **Modern App Architecture:** Built on **Next.js 15 (App Router)** for peak performance, optimized routing, and React Server Components.
* **Premium UI/UX Design System:** Custom "Green & Mild Yellow" aesthetic derived directly from the hotel's historical branding. Features advanced CSS techniques including glassmorphism headers, sticky navigation, and high-fidelity Framer Motion micro-animations.
* **Live Booking Engine:** A custom "Slide-Over" interactive cart system that parses stay durations, dynamically calculates base rates against nights stayed, and generates deeply-linked, pre-filled WhatsApp messages for frictionless direct conversions.
* **SEO & Performance Matrix:** Engineered for peak Google Lighthouse scores utilizing Server-Side Rendering (SSR), dynamic Open Graph meta tags, semantic HTML5, and Next/Image aggressive optimization.
* **Responsive Fluid Typography:** Mobile-first, responsive design ensuring a flawless, app-like experience across all viewport dimensions.

## 🛠 Technical Stack

- **Core Framework:** Next.js 15 (App Router, TypeScript)
- **Styling Engine:** Tailwind CSS v4
- **Animation Library:** Framer Motion
- **Iconography:** Lucide React
- **Media Carousels:** Embla Carousel React
- **State Management:** React Context API (`BookingContext` & `useBooking` hook)
- **Date Parsing:** `date-fns`

## 🚀 Development Setup

To run this project locally for maintenance or further feature development:

1. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

3. **Access the application:**
   Open [http://localhost:3000](http://localhost:3000) in your browser.
